# Fable5 — Автономная Элиза с защитой ядра

Защищенный локальный ИИ-ассистент на базе модели Llama (`llama.cpp`) с долгосрочной памятью, безопасным поиском в сети и изолированной песочницей для управления ОС.

## 🚀 Быстрая установка и запуск (Инструкция)

### Шаг 1: Подготовка Питера (Python)
Убедитесь, что у вас установлен Python версии 3.10 или новее.

### Шаг 2: Установка зависимостей
Откройте терминал/командную строку в папке с проектом и пропишите одну команду для установки всех библиотек:
```bash
pip install -r requirements.txt
```

### Шаг 3: Загрузка нейросети (Модели)
1. Создайте в корневой папке проекта подпапку с именем `models`.
2. Скачайте любую интересующую вас модель в формате `.gguf` (например, Llama-3, Gemma или Qwen) с сайта Hugging Face.
3. Положите скачанный файл внутрь созданной папки `models` и переименуйте его ровно в `model.gguf`.

### Шаг 4: Старт
Запустите ИИ-ассистента командой:
```bash
python fable5.py
```

---

## 🛠️ Доступные команды в чате:
* Простой текст — обычное общение с Элизой.
* `найди [ваш запрос]` — безопасный поиск актуальной информации или картинок в интернете.
* `код` — запуск режима самоанализа архитектуры ИИ.
* `выход` — безопасное сохранение кратковременной памяти и завершение процесса.
