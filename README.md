# 🧠 ELIZA v5 — Шпаргалка капитана

## 1. Главные команды в PowerShell (работают из любой папки)
- `eliza` — запустить саму Элизу (`fable5.py`). При выходе (`выход`) сама сохранит память и очистит видеокарту!
- `off` — **Игровой рубильник**: мгновенно выгружает нейросети из GTX 1650 и ОЗУ перед играми.
- `save` — создать точку сохранения (коммит кода в Git + снимок дневника и памяти в `.snapshots`).
- `stat` — посмотреть, что сейчас сидит в памяти Ollama.
- `python agent.py fable5.py "задача"` — твой личный быстрый JSON-инженер (проверяет код в песочнице перед записью).
- `ccf` / `cc` — запуск Claude Code (`coder-fast` или `fable5`).

## 2. Ярлык на Рабочем столе
- **`Eliza_Hub.bat`** — меню запуска в один клик (1 — Элиза, 2 — Кодер, 3 — Очистка GPU под игры).

## 3. Структура проекта (`D:\fable5`)
- `fable5.py` — главный код Элизы (личность, дневник, поиск в сети, защита ядра).
- `agent.py` — локальный JSON-агент с проверкой синтаксиса через `py_compile`.
- `CLAUDE.md` — паспорт проекта и правила безопасности для ИИ-агентов.
- `fable_diary.txt` / `chat_memory.json` — личный дневник и память диалогов.
- `models/model.gguf` — веса твоей 8.9 ГБ модели (не трогать).

## 4. Полезные команды Git (если захочется откатить правку)
- `git diff fable5.py` — посмотреть, что изменилось в коде.
- `git checkout fable5.py` — мгновенно вернуть рабочий код до правки.
